# Leca-VC

Leca-VC (LLM-Empowered Cell-Agent Virtual Community) is a computational
framework for forward simulation of multicellular tissue dynamics from early
omics observations while preserving cell-state heterogeneity and explicit,
traceable cellular decision programs.

This repository contains the code, figure-generation workflows, benchmark
entrypoints, and reproducibility metadata associated with the Leca-VC
manuscript.

## Release status

This repository is currently maintained as a private release candidate.
Public release will follow final manuscript, reproducibility, and data-release
checks.

The manuscript and supplementary PDFs associated with the current release
candidate are the authoritative references for figure numbering and reported
numerical results. Release-specific provenance and reproducibility status are
recorded in:

- `manifests/release_status.json`
- `manifests/code_entrypoints.json`

## Repository structure

- `experiments/` — supported benchmark entrypoints
- `scripts/` — scientific implementation and shared modules
- `workflows/` — figure reproduction and benchmark execution
- `figures/` — frozen reference figure assets
- `source_data/` — small source-data files suitable for Git
- `manifests/` — release and dependency metadata
- `tests/` — validation and reproducibility checks
- `environment/` — reproducible software environments

Figure 1 is an author-created schematic and is not generated by the scientific
